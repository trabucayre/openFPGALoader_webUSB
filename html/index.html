openFPGALoader WEB interface

Note: for Linux users, ftdi_sio driver must be unloaded with sudo modprobe -r ftdi_sio

Note: Google Chrome must be used: USB access is not supported by firefox

This page offers two ways to program an FPGA directly from a navigator:

  • Manual mode requires openFPGALoader's argument exactly as done via a terminal
  • Automatic mode allows users to select:
    • target board and/or cable via a list
    • bitstream destination (SRAM or Flash). For Flash access a verification step may be optionally performed after write.
    • the bitstream file
